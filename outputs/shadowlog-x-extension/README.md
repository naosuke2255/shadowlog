# SHADOWLOG QR Collector（Chrome / Edge用）

Xの検索・投稿画面で、スクロールして表示した画像からWBのデッキQRを収集する個人用拡張です。X公式APIや有料API契約は使いません。

## 初回の導入

1. `shadowlog/start.cmd` でアプリを起動します。
2. Chromeなら `chrome://extensions`、Edgeなら `edge://extensions` をアドレス欄に入力します。
3. 「デベロッパーモード」（開発者モード）をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押し、この `shadowlog-x-extension` フォルダーを選択します。ZIPそのものではなく、展開したフォルダーを選んでください。
5. 拡張一覧のSHADOWLOG QR Collectorをツールバーに固定します。

公式ストアでの公開は行っていません。ファイルの導入・実際のX画面でのブラウザー拡張実行は未検証です。Chrome／Edgeのブラウザーによる初回権限表示を確認して導入してください。

## 使い方

1. **同じChrome／Edgeで**Xを開いてログインし、「エルフ 連勝」などを検索。画像を探しやすいよう画像タブ等を選びます。
2. 拡張アイコン →「このX画面で開始」。
3. 小窓を閉じ、普段どおりゆっくりスクロールします。開始後に画面内へ表示された投稿画像を、1回につき最大100枚読み取ります。ページ内の画像が読み込まれる前に通過したものは拾わないことがあります。
4. 拡張を再び開くと、検出したデッキが表示されます。最大30件を選択し「選択したデッキを比較へ送る」を押します。
5. `http://127.0.0.1:4173` の差分チェッカーが開き、40枚を検証して自動追加します。送信に失敗しても拡張の候補は残ります。先にサーバーを起動してから再送できます。
6. 読み取りを止めるにはXのタブで拡張を開き「停止」。Xのページ再読み込みでも停止します。上限に達した後は再び開始できます。

画面に出していない検索結果は取得しません。人気順や検索語はX側で操作してください。デッキの強さ、投稿の人気、連勝数の正しさは判定しません。

同じカード構成は重複しません。拡張内に最大100構築を保持し、アプリの比較対象は最大30構築です。送った後の「一覧を空にする」は拡張内の候補だけを消し、アプリの比較データは変更しません。1画像に複数QRがある場合は最初に読めたQRを対象とします。

## Windows版Xについて

EdgeでインストールしたWebアプリ版なら拡張が利用できる場合がありますが、Windows版Xの種類やブラウザープロファイルにより異なります。拡張が表示されない場合は、SHADOWLOGの「Xからデッキ収集」→「Xの画面を選ぶ」を使ってください。この画面共有方式では拡張をインストールする必要はありません。

## 保存場所と権限

- `activeTab` / `scripting`：開始操作をしたXのタブへ読取処理を入れるため。すべてのサイトを常時読む権限は要求しません。
- `https://pbs.twimg.com/*`：画面上で見つかったXの投稿画像をQR解析用に取得するため。取得先は実装でも `pbs.twimg.com/media/` に限定し、Cookieを付けずに取得します。
- `storage`：検出したデッキURL・元投稿URL・取得日時・進捗をChromeの拡張用ローカル保存領域に保存します。画像本体は保存しません。
- アプリへの受け渡しはURLフラグメントで行い、サーバーへ画面画像を送信しません。URLから受け取った40枚はアプリ側で再検証します。
- 送信先アプリのデータは**拡張を使ったChrome／EdgeのlocalStorage**です。Codex内蔵ブラウザーの既存データとは別です。必要ならJSONバックアップをそのブラウザーへ復元してください。

QR解析：同梱jsQR 1.4.0 / Apache-2.0（`vendor/jsQR.LICENSE`）。インターネットからプログラムを動的読み込みしません。Xの画面構造や画像配信仕様が変わると修正が必要になる場合があります。

導入手順参考：https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world
