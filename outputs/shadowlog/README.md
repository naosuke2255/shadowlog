# SHADOWLOG

Shadowverse: Worlds Beyond の個人用対戦分析Webアプリです。日本語・ダークテーマで、対戦記録、基本集計、マッチアップ、マリガン、デッキバージョン比較の順に実装しています。アカウント登録、依存パッケージのインストールは不要です。戦績・メモはローカル保存です。副操縦士の新規シート生成時のみ、公式サイトへカードIDを指定して公開カード情報を取得します。

## Web版を使う

Vercelで公開したURLをPCまたはスマートフォンのブラウザーで開きます。インストールやアカウント登録は不要です。対戦データは利用中のブラウザーの localStorage に保存され、VercelやGitHubには送信されません。

## ローカル起動

Node.js 22以上を使用します。このPCではNode.js 24で動作確認しました。

1. このフォルダーの `start.cmd` をダブルクリックします。またはこのフォルダーで `node server.mjs` を実行します。
2. ブラウザーで **http://127.0.0.1:4173** を開きます。
3. 終了時は起動したウィンドウで Ctrl+C を押します。

`index.html` の直接ダブルクリックではなく、Vercelの公開URLまたは上記ローカルURLで使用してください。ローカルサーバーは初期状態でこのPCからのみアクセスできます。ポート4173が使用中なら既に起動していないか確認してください。

## 最初の記録

1. 「デッキ・バージョン」でデッキ名とクラスを設定し、カードリストを登録します。
2. 次のいずれかで40枚を登録します。
   - **公式URLで一括取込**：Deck Portalのデッキ詳細画面で「デッキURLをコピー」し、「公式デッキURL」に貼って「URLから取り込む」を押します。40枚とクラスをセットし、内容確認後に保存します。対応形式は `https://shadowverse-wb.com/ja/deck/detail/?hash=…` です。短いデッキコードは対象外です。QR画像は下記の画像取り込みを使用してください。
   - **カード検索**：名前の一部を検索して「＋」で1枚追加、「3枚」で一括設定できます。「りのせうす」でも「リノセウス」に一致します。選択済みのカードは「−」「＋」で調整できます。候補は選択クラスとニュートラルが初期値で、全クラス・登録済みに切り替えられます。
   - **まとめて貼り付け**：折り畳み欄に `カード名 3`、`カード名 ×3`、`3x カード名`、カード名の次行に枚数、などで貼り付けて反映します。候補にないカードも「カード名 枚数」で追加できます。

   同名3枚・合計40枚の上限を確認します。取込や貼り付けだけでは保存されません。デッキ名を設定して「デッキを保存」で確定してください。
3. 「既定にする」で普段使うデッキを指定します。既定がない場合は使用回数が多いデッキを選択します。
4. 「対戦を記録」で、相手クラス・先攻/後攻・勝敗を選び、カードボタンを4回押して初手を埋めます。同名カードの上限も考慮します。各欄の選択メニューでも変更できます。
5. 返したカードだけ「キープ」を押して「返す」にし、引き直したカードを選びます。終了ターンを確認して保存します。Ctrl+Enter / Command+Enterでも保存できます。

日時は入力を開始した端末のローカル日時が初期値です。「日時を変更」で修正できます。初手は依頼仕様どおり4枚です。終了ターンは初期値8、1〜99の整数です。相手・手番・勝敗は誤入力を避けるため毎試合選択します。デッキとバージョンは保存後も引き継ぎます。履歴の「詳細・編集」で初手も含めて確認・修正・削除できます。

## デッキ変更

保存した40枚のリストは固定です。「新バージョンを作成」で現在のリストを複製し、カードを変更して別名のバージョンとして保存します。1枚の変更でも保存でき、旧バージョンの対戦はそのまま維持されます。変更差分もカードリスト欄で確認できます。同じリストの並び替えだけでは新バージョンにしません。

## 分析の定義

- 全画面で期間（開始・終了日を含む）、デッキ、バージョン、相手クラス、手番を絞り込めます。
- 総合勝率、総試合数、直近20/50戦、連勝/連敗、先攻/後攻、クラス別、デッキ別、バージョン別、平均決着ターンを表示します。
- 直近・連勝/連敗も現在の絞り込み内で計算します。同一日時の場合は後から記録した試合を最新にします。試合がない場合は勝率「—」と0戦、20/50戦に満たない場合は存在する試合のみで計算します。
- 勝率はすべて勝数と試合数を併記します。引き分けは今回の記録対象外です。
- マリガンの初手回数・キープ回数は**カードの枚数**として表示し、キープ率はキープ枚数÷初手枚数です。
- キープ勝率はそのカードを1枚以上キープした**試合**、返却勝率は1枚以上返した**試合**で集計します。同名カードを2枚引いても試合数は1です。
- 同名カードを一部キープ・一部返却した試合は一覧では両群に含みます。「キープ / 返却の比較」ではその重複試合を両群から除外します。先攻・後攻・相手クラス別キープ勝率と各サンプル数も表示します。
- 勝率差は観察結果です。他の初手、対面、期間などの偏りがあるため、キープやデッキ変更による因果効果を示すものではありません。

## 対面攻略メモ

各相手クラスごとに「残したいカード」「警戒するカード」「基本的なゲームプラン」「自由メモ」を保存します。「メモを保存」で確定してください。対戦記録で相手を選ぶと参照できます。画面幅によって入力欄の下に表示されます。

## データ保存場所

ブラウザーの **localStorage** に保存します。サーバーのフォルダーに対戦データは書き込まれません。

| キー | 内容 |
| --- | --- |
| `shadowlog.data.v1` | 自分の対戦、デッキ、バージョン、攻略メモ、既定デッキ |
| `shadowlog.previous.v1` | 最後の保存直前の状態（1世代） |
| `shadowlog.demo.v1` | 実データとは分離したデモデータ |

保存領域はブラウザー・プロファイル・URLごとに異なります。Vercelの公開URL、独自ドメイン、`localhost`、`127.0.0.1` はそれぞれ別の領域です。URLを変更する前にJSONを書き出し、移行先で復元してください。ブラウザーのデータ削除やプライベートモード終了で失う可能性があるため、JSONを定期的に保存してください。破損データは自動上書きせず、復元画面から復旧できます。保存容量を超えた場合はエラーを表示し、メモリー上の記録も成功扱いにしません。別タブで更新された場合は再読み込みするまで保存を止めます。

## エクスポート・インポート・バックアップ・復元

「データ・バックアップ」で操作します。

- **JSONバックアップ**：全データを書き出します。復元にはこちらを使用します。
- **追加インポート**：JSONを読み込み、IDが同じ対戦は重複させません。同一IDで内容が異なる場合は処理を中止します。攻略メモが重なる場合は現在のメモを優先します。
- **このファイルから復元**：確認後、JSONの内容で全体を置き換えます。通常モードでは置換前の状態を1世代保存します。
- **直前の保存状態に戻す**：通常モードで最後の変更前の状態に戻します。長期バックアップの代用ではありません。
- **保存中の生データを退避**：読み込めなくなった元データの保全にも使用できます。
- **対戦CSV**：Excel等で閲覧するためのUTF-8 BOM付きCSVです。初手・キープ・返却・引き直しを含みます。CSVのインポートはありません。バックアップ/復元はJSONで完結します。

ファイル保存が始まらない内蔵ブラウザーでは、書き出し時に表示される「内容をコピー」を使い、テキストエディターに貼り付けてUTF-8の `.json` / `.csv` として保存してください。

JSONは25MBまで。40枚の枚数、対戦参照先、初手、勝敗、手番、クラス等を検証してから反映します。複数端末の自動同期はありません。スマートフォンへはJSONを渡してインポートしてください。

## スマートフォンで閲覧する

390px幅でレスポンシブ表示を確認しています。表とナビゲーションは横スクロールできます。

スマートフォンではVercelの公開URLへアクセスしてください。データはそのスマートフォンのブラウザー内に保存され、PCとはJSONで受け渡します。副操縦士の新規シート生成にはVercel Functionの `/api/cards` を使用し、QR画像の解析や保存済みシートの閲覧はブラウザー内で行います。ローカルサーバーはPC自身に限定しているため、スマートフォンからPCの127.0.0.1にはアクセスできません。

## カード候補の更新と制限

2026-09-17に[公式Deck Portalカード一覧](https://shadowverse-wb.com/ja/deck/cardslist/)の公開表示から取得した811件・810種類の名前を同梱しています。同名再録は検索ではまとめます。カード画像や効果文は収録していません。URL内のカードIDはこの同梱データと照合し、未知のIDがある場合は全体の取り込みを中止して元の編集内容を保持します。

候補検索も共有URLの解析も端末内で処理します。公式へのログインや通信は不要です。最新弾の自動更新、フォーマットの使用可否・禁止制限の自動判定はありません。未収録カードは貼り付け欄から追加できます。公式の共有URL形式が変わった場合は解析処理の更新が必要です。

## 対戦中の副操縦士（1.2）

1. 「対戦中の副操縦士」で相手の公式デッキ詳細URLを貼り、「警戒表を生成」を押します。40枚を自動取得します。
2. 自分のURLも指定できます。指定しなければ登録済みデッキから選択でき、既定デッキの最新バージョンが選択されます。
3. 相手PPを選択し、「現在〜次のPP」「現在PP以下」「全PP」を切り替えます。疾走・AOE・確定除去・回復・超進化・守護で絞り込めます。
4. 使用されたカードの「使用 ＋」をクリックすると残り最大枚数が減ります。「−」または「1つ戻す」で訂正。「次の試合」で使用枚数とPPをリセットします。
5. 「能力・警戒設定」で公式能力文・関連カードを確認し、警戒度、想定PP、タグ、1枚の打点・回復量、条件メモを編集できます。
6. 「マリガン・勝ち筋を編集」に優先キープ、条件キープ、ゲームプラン、自分用メモを保存します。既存のクラス別攻略メモは生成時にコピーします。その後はシートごとに独立します。
7. 「対戦用ミニ表示」でナビゲーションを隠し、ゲームの横に置く表示に切り替えます。「通常表示」で戻せます。「シートをコピー」でテキストを取り出せます。

シート、取得済み能力文、使用枚数、PP、警戒設定、対面メモは `shadowlog.data.v1` の `copilot` に保存します。既存のJSONバックアップ・復元にすべて含まれ、取得済みシートはネット接続なしで使用できます（ローカルサーバーの起動は必要）。追加インポートで同一IDの内容が異なる場合は中止します。

### 警戒表の読み方

- タグは公式の通常能力文・進化後・関連カード・クレスト等に基づく候補判定です。発動条件を満たすことや、そのPPで必ず使えることは保証しません。エンハンス、コスト軽減、生成先の能力などは条件メモと警戒PPで補正してください。
- 残り最大枚数は代表構築の採用数から使用済みを引いた値です。実際の相手構築、手札、生成、回収、再利用は追跡しません。
- 参考打点・回復は、設定した1枚あたり数値を現在PP内で最大化した組み合わせです。残り枚数の制約は考慮します。手札・盤面・進化・コンボ・コスト変化は計算しないため、実際の最大打点ではありません。未設定枚数を併記し、未設定と0を区別します。無条件の単純な疾走等のみ自動で数値設定します。
- マリガンと勝ち筋は自分で入力する知識です。カードリストから戦術の正しさを自動判定する機能はありません。
- 新規生成時の接続先は公式 `https://shadowverse-wb.com/web/CardList/card` に固定しています。ブラウザーの戦績・メモは送信しません。カード情報はサーバー内で1時間キャッシュします。公式仕様が変わると新規取得できなくなる可能性があります。取得日を画面に表示し、能力変更後は新しいシートを作成してください。
- 短いデッキコード・攻略サイト固有URLは未対応です。Deck Portalの40枚入り共有URLを使用してください。

テストはこのフォルダーで `npm test` を実行します。


## QR画像から取り込む（1.3）

「デッキ・バージョン」→「QR画像から取り込む」で、ゲーム内やDeck Portalのデッキ共有QRを含む画像を選びます。スクリーンショット全体も対応します。画像を枠内にドロップするか、枠をクリックしてCtrl+Vでも読み込めます。読み取り後はカード名・採用枚数・クラスを自動入力するため、デッキ名を付けて保存してください。既存デッキに反映する場合は先に「新バージョンを作成」を選びます。

副操縦士にも自分・相手それぞれのQR画像欄があります。読み取り後に「警戒表を生成」を押します。画像自体はブラウザー内で処理し、サーバーに送信・保存しません。PNG/JPEG/WebP/BMP、20MB以下を想定。読めない場合はQR全体と白い余白を含めて切り抜いてください。カメラ撮影・短いデッキコードは対象外です。

QRデコーダーは同梱の jsQR 1.4.0（Apache-2.0）。ライセンスは `vendor/jsQR.LICENSE`。外部CDNへの接続は不要です。

全テストはこのフォルダーで `npm test` を実行します。


## デッキ差分チェッカー（1.4）

サイドバーの「デッキ差分チェッカー」を開き、公式URLを1行に1つ貼ってまとめて追加します。QR画像、登録済みのデッキ・各バージョンも追加できます。最大30構築、同じ構築は重複除外し、異なるクラスはクラスごとに比較します。

- 共通枠：各カードの全構築での最小採用枚数を合計。
- 自由枠：40枚から共通枚数を引いた数。
- 採用率：1枚以上採用した構築数 / 比較構築数。サンプル数・採用枚数の最小〜最大・全構築平均を併記。
- 基準デッキ→比較先デッキ：抜く枚数をマイナス、追加する枚数をプラスで表示。
- 比較一覧で名前変更・対象から外す操作が可能。元の登録デッキは変更されません。

比較対象はブラウザー内の同じ保存データの `comparison` に保持し、既存JSONバックアップ・復元に含まれます。画面の「比較結果をコピー」でテキストを持ち出せます。集計は追加した構築だけを対象とし、環境全体の採用率ではありません。


## Xからデッキ収集（1.5・X API不要）

### Windows版Xをそのまま使う：画面読み取り

1. ChromeまたはEdgeでVercelの公開URL（ローカル版では `http://127.0.0.1:4173`）を開き、「Xからデッキ収集」へ。
2. Windows版Xで検索し、デッキ画像を拡大します。
3. アプリの「Xの画面を選ぶ」を押し、ブラウザーの画面共有ダイアログでXウィンドウを選択します。
4. 約1.5秒間隔で表示中のQRを読取り、40枚のデッキを差分チェッカーへ自動保存します。Xで別の画像を表示すれば続けて収集できます。
5. 終了時は「読み取り停止」。このアプリで別の画面へ移動した場合も共有トラックを停止します。

画面の映像・音声は送信・ファイル保存しません（音声は取得しません）。処理中のみブラウザーのメモリー上に描画します。QRのない画像、読み取れない小さなQR、未知カードは取り込みません。QRを拡大し白い余白まで表示してください。最小化・ブラウザーのバックグラウンド制限・共有対象の表示状態により読み取りが遅くなることがあります。読み取りは現在の1画面の1つのQRを対象とします。画面方式は元投稿URLを自動取得しません。

画面共有非対応の内蔵ブラウザーではChrome／Edgeで開いてください。共有ウィンドウはユーザーが選択する必要があります。こちらで実際のWindows版Xへの画面接続は未実施です。

### Chrome／EdgeのX検索結果をスクロールして集める：拡張

同梱の `../shadowlog-x-extension/README.md` の手順で拡張を読み込みます。X検索画面で拡張の「開始」を押し、スクロールして表示した画像からQRを収集します。「比較へ送る」でこのアプリを開き、重複を除いて追加します。APIキーやX開発者登録・API料金は不要です。

比較対象は最大30構築。Xでの人気順や画像検索はX画面で選択してください。人気度や連勝の真偽をこのツールが判定する機能はありません。

Chrome／EdgeとCodex内蔵ブラウザーのlocalStorageは別です。既存データを同じ場所で使いたい場合、これまでのブラウザーからJSONを書き出し、使用するChrome／Edgeで復元してください。ブラウザーをまたいだ自動同期は行いません。

### 保存画像の一括取り込み

同画面の「保存画像をまとめて読む」で1〜30枚のQR画像を選択できます。読み取れない画像をスキップし、成功・重複・失敗を別々に表示します。

比較の構築情報、元デッキURL、拡張で取得した元投稿URL、取込日時は既存JSONバックアップに含まれます。拡張内の未送信候補はブラウザー拡張の保存領域で管理されます。

全テストはこのフォルダーで `npm test` を実行できます。拡張フォルダーはアプリと同じ親フォルダーに置いてください。

## ミニモード（1.6）
左メニューの一番上「ミニモード」を選択し、ブラウザーのウィンドウ幅を約360〜480pxにしてゲームの横に置いてください。相手クラス→先攻／後攻→勝ち／負けの3クリックで簡易記録できます。デッキとバージョンは引き継ぎ、相手と先後は保存ごとにリセットして二重保存を防ぎます。相手を選ぶと攻略メモも表示します。常に最前面に固定する機能はありません。
初手と終了ターンは省略できます。未入力のターンは平均から、初手はマリガン分析から除外します。勝率・対戦数には含めます。「対戦履歴・詳細を補完」から初手4枚と終了ターンを入力すると通常の記録になります。簡易記録も既存のローカル保存・JSONバックアップに含まれます。旧版アプリでは簡易記録の読込に対応しないため、復元は1.6以降をご利用ください。

## デッキタイプ・キープのみの記録（1.7）
通常入力・ミニモードとも、相手クラスを選ぶと「相手デッキタイプ」が表示されます。「タイプを追加」からクラス別に好きな名称を登録でき、次回以降は選ぶだけです。ビショップには「進化ビショップ」「アミュレットビショップ」を用意しました。判別できない場合は未分類のまま保存できます。クラスを切り替えるとタイプもリセットします。
マッチアップ分析に相手タイプ別勝率を追加。各分析画面の「相手デッキタイプ」で期間・手番などと組み合わせて絞り込めます。分類はJSONバックアップ・追加インポートに含まれ、対戦CSVにも出力されます。
マリガン入力は両モードともキープしたカードのみ（0〜4枚）。カードボタンを残した枚数分押し、選択済みカードを押すと外せます。「全返し（0枚）」も選べます。返したカードや引き直しの入力はありません。
新形式はキープ勝率・先後別・相手別のキープ勝率に含めます。初手に来た枚数、キープ率、返却との比較は算出できないため、過去の全初手記録のみを集計します。旧記録は閲覧や他項目の編集で保持し、キープ内容を変更した場合のみ新形式に切り替えます。新形式を含むバックアップの復元には1.7以降を使用してください。

## Vercelで公開する

1. VercelでGitHubリポジトリ `naosuke2255/shadowlog` をImportします。
2. **Root Directory** を `outputs/shadowlog`、**Framework Preset** を `Other` にします。
3. **Build Command** はOverrideを有効にして空欄にします。**Output Directory** はOverrideを無効のままにします（`public` フォルダーがないため、Root Directory直下が配信されます）。依存パッケージや環境変数の追加は不要です。
4. 公開後にトップ画面が表示されることと、「対戦中の副操縦士」で公式デッキURLからシートを生成できることを確認します。

`index.html` などは静的配信され、`api/cards.js` だけがVercel Functionとして動作します。クライアントはローカル版と同じ `/api/cards` を呼ぶため、接続先の切り替えは不要です。Vercel側では公式サイトから取得したカード情報をFunctionインスタンス内で最大1時間キャッシュしますが、インスタンスが終了した場合は破棄されます。

### 標準デッキタイプ候補（2026-09-19確認）
全7クラス33種類を同梱し、未登録でも通常・ミニモードと集計フィルターで選択できます。自作の分類や既存記録の分類も維持します。過去環境・アンリミテッドを含む記録用名称で、現在の強さや使用可能フォーマットを保証する一覧ではありません。自動更新は行いません。
